# Prompt Vault (Tallron)

Categorized on-node library of named prompts with optional **1024×1024**
reference images. Categories on the left filter the list; click a prompt to
preview its image; **Copy** sends the text to the STRING socket (`text`) and
the clipboard.

## Features

- **Categories** (left panel) — **All** shows every prompt; click a category to filter
- **+ Category** — create a category; double-click the name to rename; × to delete
- **+ Add Prompt** — inserts a blank prompt in the active category (or Uncategorized under All)
- **Title** always visible — **double-click** to rename; **click** to select
- **+ / −** expands or collapses the prompt body
- **Copy** — clipboard + STRING output (green border = selected)
- **Tiny thumbnail** on each row when an image is attached
- **Right panel** image preview; **Load Image** resizes to 1024×1024 (center-crop cover)
- **Draggable divider** between list and preview to resize the image panel
- **Click the preview** — lightbox of the full 1024 image; **Clear** removes it
- Drag handle reorders prompts; Import / Export JSON (categories + images)

## Usage

1. Drop **Prompt Vault** from **Tallron Handy Nodes**
2. Add categories and prompts; select a category to filter
3. Click a row to select (sets `text` output); **Copy** also copies to clipboard
4. **Load Image** attaches a 1024×1024 reference to the selected prompt
5. Drag the vertical divider to resize the preview
